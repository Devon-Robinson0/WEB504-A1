# Personal Portfolio Website

A responsive personal portfolio website for Devon Robinson. The website presents personal information, technical skills, projects, and contact information in a professional and accessible format.

## Features

* Home page with personal introduction and background
* Projects page showcasing completed and ongoing projects
* Skills page presenting technical skills and technologies
* Contact page with a contact form
* Responsive design for desktop, tablet, and mobile devices
* Navigation between the main portfolio pages
* Links to external profiles such as GitHub and LinkedIn

## Technologies Used

* HTML5
* CSS3

## Dependencies

The website does not require any additional software, frameworks, or packages to run.

The website contains external links to services such as GitHub and LinkedIn. These links depend on those external services being available and the associated profiles remaining accessible.

## Running the Website Locally

Download or clone the repository and open the index.html file in a modern web browser.

The website does not require any installation or additional dependencies to run locally.

## GitHub Pages

The website is designed to be hosted using GitHub Pages.

## Browser Requirements

The website is designed for modern web browsers that support current HTML5 and CSS3 standards.

Recommended browsers include Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari.
